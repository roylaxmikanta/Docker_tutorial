Install Docker Desktop
Sign in to Dockerhub and Docker Desktop
Assure that you're logged in:----> docker login
Docker Desktop:
> Check docker install: cli -> "docker"
> Pull the hello-world image and run it

Build docker image:--------------> docker build -t mlops-docker-demo.
Run the container:--------------->docker run -p 5000:5000 mlops-docker-demo
Tag your image:------------------>docker tag mlops-docker-demo lkanta15/mlops-docker-demo:latest
Push image to dockerhub:---------> docker push lkanta15/mlops-docker-demo:latest
Pull image from dockerhub:-------> docker pull lkanta15/mlops-docker-demo:latest
Run the Pulled image:------------> docker run -p 5000:5000 lkanta15/mlops-docker-demo:latest
